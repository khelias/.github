# Contributing

These are one person's family projects, kept in public. Issues are welcome: a bug, a question or an idea.

Open a pull request only after an issue has agreed on the change; one that arrives unasked may be closed.

Each repository's `AGENTS.md` has its commands and conventions, and the rules every repository shares are in [khe-workspace `AGENTS.md`](https://github.com/khelias/khe-workspace/blob/main/AGENTS.md). Security reports go through [SECURITY.md](SECURITY.md), not issues.
